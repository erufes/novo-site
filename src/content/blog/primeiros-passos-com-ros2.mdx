# Primeiros passos com ROS 2

O **ROS 2** (Robot Operating System 2) é o middleware que usamos para conectar
sensores, atuadores e algoritmos nos nossos robôs. Apesar do nome, ele não é um
sistema operacional — é um conjunto de bibliotecas e ferramentas para construir
aplicações robóticas distribuídas.

## Conceitos centrais

| Conceito  | O que é                                                    |
| --------- | ---------------------------------------------------------- |
| Nó (node) | Um processo que executa uma tarefa específica              |
| Tópico    | Canal de comunicação assíncrona entre nós                  |
| Mensagem  | A estrutura de dados que trafega por um tópico             |
| Serviço   | Comunicação síncrona do tipo requisição/resposta           |

## Um nó mínimo em Python

```python
import rclpy
from rclpy.node import Node

class OlaMundo(Node):
    def __init__(self):
        super().__init__("ola_mundo")
        self.get_logger().info("Nó iniciado!")

def main():
    rclpy.init()
    rclpy.spin(OlaMundo())
    rclpy.shutdown()
```

Esse nó simplesmente sobe, registra uma mensagem no log e fica vivo até receber
um sinal de encerramento. A partir daí, é só adicionar _publishers_ e
_subscribers_ para começar a trocar dados.
