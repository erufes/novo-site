# Fotos dos projetos

Uma foto por projeto.

## Padrão obrigatório

- Formato: **PNG**
- Nome do arquivo: **`<slug>.png`** — o mesmo `slug` do projeto em
  `src/data/projects.ts`.
- Recomendado: imagem em paisagem (ex.: 1200×675, proporção 16:9) — é exibida
  como capa no card e como banner na página do projeto.

> Enquanto a foto não existir, o card e a página mostram o ícone do projeto como
> fallback. Nada quebra.
