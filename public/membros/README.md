# Fotos dos membros

Coloque aqui a foto de cada membro/professor.

## Padrão obrigatório

- Formato: **PNG**
- Nome do arquivo: **`nome_sobrenome.png`** — primeiro nome + último sobrenome,
  tudo minúsculo, sem acentos e sem espaços (use `_`).
- Recomendado: imagem quadrada (ex.: 400×400) — ela é exibida recortada em
  círculo no card.

> Enquanto a foto não existir, o card mostra as iniciais do membro
> automaticamente. Nada quebra.
